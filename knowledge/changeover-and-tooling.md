# Changeover and tooling

## Changeover
Changing a machine from one product family to another takes about 20 minutes for tool and fixture changes. The
scheduler does not model changeover time, so the schedule can be slightly optimistic when it alternates families.

## Tooling
Shaft tooling is shared between M3 and M4 and is never needed on both at once. A tooling crib on the shop floor
holds one spare set of gear cutters.
