# SOP: changing an order's priority

## Priority scale
Priorities run from 1 (lowest) to 5 (highest). Priority 5 is reserved for orders with a contract penalty or a
safety-related use. A customer asking for it by phone is not enough; the order must be flagged by sales.

## Logging
Every priority change is logged with who asked, the reason and the time. A change made during a shift takes
effect at the next planning run, not retroactively for work already started.

## Limits
No more than 3 orders may hold priority 5 at the same time. If a fourth is requested, the planner asks the
production manager which of the current three drops to priority 4.
