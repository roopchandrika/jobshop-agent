# SOP: machine breakdown

## First response
When a machine stops unexpectedly, the operator presses the stop button, tags the machine "DOWN" and calls
the maintenance desk on extension 4100. The shift lead records the time the machine stopped in the shift log.
The planner is told within 10 minutes.

## Work in progress
An operation that was running when the machine stopped is scrapped from the machine's point of view: it
restarts from the beginning once a machine is available. Partly finished parts are inspected before reuse.
Operations that had not started are re-planned.

## Estimating the outage
Maintenance gives a first estimate of the repair time within 30 minutes of the call. Planners should plan on the
estimate plus a 20 minute warm-up before the machine runs production again. If the estimate is more than 4
hours, the production manager must be informed.
