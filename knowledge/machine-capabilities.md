# Machine capabilities

## Which machine does what
M1 can turn, mill and drill. M2 can mill, drill and grind. M3 can drill, grind and turn. M4 can grind, turn and
mill. Every kind of operation can run on exactly three of the four machines.

## Bottlenecks
Grinding runs only on M2, M3 and M4, and most shafts, gears and housings need a grinding step, so grinding
capacity is usually the bottleneck. Losing one grinding machine hurts more than losing M1.
